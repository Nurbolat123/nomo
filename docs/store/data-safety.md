# Google Play — Data safety · App Store — App Privacy

Ответы для анкет. Шифрование при передаче — да (HTTPS). Удаление данных по запросу — да
(в приложении и на странице `https://<ваш-домен>/delete-account`, её отдаёт бэкенд).
Данные третьим лицам не продаются, рекламы и трекинга нет.

## Nomo (пассажир)

| Данные | Собирается | Зачем | Связано с пользователем | Обязательно |
| --- | --- | --- | --- | --- |
| Номер телефона | да | вход, связь водителя с пассажиром | да | да |
| Имя | да | показывается водителю | да | нет |
| Точное местоположение | да, только когда приложение открыто | адрес подачи, машины рядом | да | нет (можно выбрать адрес вручную) |
| Платёжная информация | токен карты и последние 4 цифры; номер карты хранит банк | оплата поездок | да | нет |
| История покупок (поездки) | да | история, чеки, поддержка | да | да |
| Сообщения в приложении | да (чат с водителем) | связь во время поездки | да | нет |
| Сбои и диагностика | после подключения Sentry | стабильность | нет | — |

**Передача третьим лицам:** водителю видны имя, адреса поездки и рейтинг; банку-эквайеру — данные для оплаты;
SMS-провайдеру — номер телефона; Google/Apple — токен push-уведомлений.

## Nomo Driver

| Данные | Собирается | Зачем | Связано с пользователем | Обязательно |
| --- | --- | --- | --- | --- |
| Номер телефона, имя | да | вход, связь с пассажиром | да | да |
| Точное местоположение | да, **в том числе в фоне, только пока водитель на линии** (foreground service с уведомлением) | подбор заказов, показ машины пассажиру | да | да для работы |
| Фото и документы | да (удостоверение, СТС, страховка, фото машины, селфи) | проверка водителя | да | да |
| Финансовая информация | заработок, баланс, комиссия | расчёты с водителем | да | да |
| Сообщения в приложении | да | связь во время поездки | да | нет |

**Google Play:** отдельная декларация фоновой геолокации **не нужна** — приложение запрашивает только
доступ «во время использования», а работу со свёрнутым экраном обеспечивает foreground service типа
`location`. В Play Console всё равно заполните декларацию **Foreground service types → location**
с коротким видео: водитель нажимает «Выйти на линию», видит уведомление «Вы на линии», сворачивает приложение.

## App Store — App Privacy (обе программы)

Data Used to Track You: **нет**.
Data Linked to You: Contact Info (Phone Number, Name), Location (Precise Location), Financial Info
(Payment Info — пассажир; Other Financial Info — водитель), User Content (Photos — водитель;
Other User Content — чат; Customer Support), Purchases (пассажир).
Назначение для всех пунктов: App Functionality.

Эти же данные описаны в `apps/*/ios_extra/PrivacyInfo.xcprivacy` — они должны совпадать.
